## Endpoint Test

Bagian ini untuk menguji API dengan melakukan sebuah hit ke endpoint yang dituju. Tujuan ini untuk mengetahui seberapa efektifnya API ini dibuat.

### Registrasi

- Testing registrasi untuk menguji hit endpoint apakah data masuk dan diterima oleh database kemudian memberikan response sesuai dengan aturan
- Mengirimkan email ke pengguna setelah melakukan pendaftaran
- Membatalkan transaksi ketika email gagal dikirim
